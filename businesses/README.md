# businesses/

One folder per business. `my-brand/` is the scaffold the `workspace-onboard` interview renames and fills; it is not a real business. Clients, when you have them, go under `clients/<client>/` with the same shape. Every business has: `AGENTS.md` + `CLAUDE.md` (first line "<Business> workspace"), `README.md`, `business.json`, `context/`, `departments/` (only the ones it runs), `projects/`, `memory/`, `handover.md`, `routines/`, `sessions/`, `tasks/`, and optionally `wiki/`.

Never copy one business's folder to start another; run `business-onboard`.
